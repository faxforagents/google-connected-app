# Security policy

Report vulnerabilities to security@faxforagents.com.
Include the affected file or endpoint, reproduction steps and observed impact.
Do not open a public issue containing security details, credentials or fax contents.

This policy covers the package and its connections to `api.faxforagents.com` and `mcp.faxforagents.com`.
Use Gemini's OAuth flow and grant only the permissions needed for the task.
Keep API keys, OAuth tokens, client secrets and reviewer passwords out of files and prompts.
Share reviewer access through Google's private review channel.
Revoke an exposed credential and replace it.

A live send requires an approval or a policy that allows it.
Received fax text stays untrusted data and cannot authorize another action.
